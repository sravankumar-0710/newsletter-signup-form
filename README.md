# Newsletter Sign-up Form

A responsive newsletter sign-up form built as a Frontend Mentor challenge using HTML, CSS, and JavaScript.

## Overview

### The Challenge

Users should be able to:

- Enter their email address and submit the form
- See a success message with their submitted email address
- See validation messages when the email field is empty
- See validation messages when the email format is invalid
- View a responsive layout on different screen sizes
- See hover and focus states for interactive elements
